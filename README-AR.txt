OFOQ STORE — نظام استقبال طلبات حقيقي (PHP + MySQL)

المحتويات:
- index.html: واجهة المتجر الحالية مع ربط API
- store-api.js: إرسال الطلبات وإدارة لوحة الإدارة
- api.php: API آمن نسبياً لإنشاء الطلبات وإدارتها
- database.sql: الجداول والمنتجات والبلديات وأسعار التوصيل الابتدائية
- config.example.php: إعداد اتصال قاعدة البيانات
- setup-admin.php: إنشاء أول حساب مدير

طريقة التثبيت على استضافة تدعم PHP 8+ و MySQL:
1) أنشئ قاعدة بيانات MySQL ومستخدم لها من لوحة الاستضافة.
2) استورد database.sql عبر phpMyAdmin.
3) انسخ config.example.php وسمّ النسخة config.php، ثم أدخل بيانات قاعدة البيانات الصحيحة.
4) ارفع جميع الملفات إلى مجلد واحد في موقعك (مثلاً public_html/store/).
5) افتح https://your-domain/store/setup-admin.php وأنشئ اسم مستخدم وكلمة مرور قوية (12 حرفاً على الأقل).
6) احذف setup-admin.php من الاستضافة فور إنشاء المدير.
7) افتح رابط المتجر. سجلات الطلبات ستظهر في لوحة الإدارة بعد تسجيل الدخول.

ملاحظات:
- لا ترفع config.php إلى مستودع عام ولا تشارك بيانات قاعدة البيانات.
- فعّل HTTPS من الاستضافة قبل استقبال بيانات العملاء.
- سعر التوصيل الافتراضي 900 دج للمنزل و600 دج للمكتب، ويمكن تغييره من لوحة الإدارة. هذه أسعار ابتدائية وليست أسعار شركة شحن مؤكدة.
- المبلغ النهائي يحسبه الخادم من أسعار المنتجات في قاعدة البيانات، ولا يعتمد على السعر الذي يرسله المتصفح.
- هذه النسخة تنشئ طلباً حقيقياً في قاعدة البيانات وتوفر تغيير حالته. ربط شركة ECOTRACK وإرسال الطرد تلقائياً يحتاج مفاتيح API وبيانات حسابك لدى الشركة، ولم يتم تفعيله دونها.
- لا توجد بوابة دفع إلكتروني في هذه النسخة؛ طريقة الدفع الحالية عند الاستلام.
